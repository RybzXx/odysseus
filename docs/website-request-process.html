Website Request Process

An email template and a plain-language request form.

Email

Subject: Website Request Process and Additional Work Payment Terms

Hello,

To reduce confusion, every new website request must be written down before work starts. The request should state the intended result, the work included, the work excluded, the person who will provide information, and the person who will approve the result.

Normal work and additional work

Normal work includes keeping existing websites working and keeping their regular information current. New features, new sections, major changes, new processes, and separate projects are additional work.

The attached form records which category applies. It also records the expected result and the way completion will be checked.

Payment for additional work

The company is currently facing low liquidity and significant debt. Approved additional work may therefore remain unpaid until the financial crisis ends. The work remains recorded as payable.

Each approved request receives a value when the work is created or approved. The value is calculated as:

Base value + impact adjustment = total recorded value

The base value is agreed before the work starts. The impact adjustment uses one of four categories: limited, useful, important, or major. The selected category and its percentage must be written in the request form.

Large requests use stages. Each stage has its own result, acceptance check, base value, impact category, and payment record.

When payment becomes due

Payment becomes due after the agreed result is complete and accepted by the named approver. If the financial crisis delays payment, the request must record a written payment trigger. This trigger can be management confirmation that the crisis ended, confirmation that funds became available, an agreed review date, or a new written payment agreement.

How to request work

Complete the form below for each request. A change to the approved scope requires a new review. The review records any change to the result, value, impact category, stages, or acceptance check.

Thank you,
