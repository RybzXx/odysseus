Website Work and Ideas

A plain-language record of current work, possible improvements, and items that need a decision.

How to read this document

This document records work. It does not approve payment. Each new request must use the Website Request Form.

6. Record for every work item

Every item should record:

  • Plain-language name
  • Purpose
  • Current status
  • Expected benefit
  • Remaining work
  • Information needed
  • Decision needed
  • Normal responsibility or additional work
  • Person responsible
  • Next review point

7. Status choices

Idea · Under review · Approved · In progress · Waiting for information · Waiting for approval · Complete · Paused · Cancelled

8. Payment note

This record does not set a payment amount. Additional work receives its value through the Website Request Form. The approved record must contain the base value, impact category, impact percentage, total recorded value, payment trigger, and acceptance person.

9. Information still needed

The responsible people must still agree the impact percentages, the person who confirms that the financial crisis ended, the review date if payment remains delayed, and the currency for each request.
